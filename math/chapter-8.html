🔗 Illustrating Relations

A relation is any set of ordered pairs (x, y). You can show a relation as a list of pairs, a table, a mapping diagram, or a graph.

Domain

The set of all inputs (x-values).

Range

The set of all outputs (y-values).

For the relation {(1, 4), (2, 6), (3, 4)}, the domain is {1, 2, 3} and the range is {4, 6}. List each value only once.

On the coordinate plane, the first number tells how far to move left or right, and the second tells how far to move up or down.

✏️ Worked examples

Example 1: Domain and range

{(−2, 5), (0, 3), (4, 5)}

Inputs: −2, 0, 4. Outputs: 5, 3, 5. List 5 only once.

Answer: Domain {−2, 0, 4}; Range {3, 5}

Example 2: From a table

x: 1, 2, 3   y: 2, 4, 6. What is the rule?

Each y is double its x.

Answer: y = 2x

Example 3: Quadrant

In which quadrant is (−3, 4)?

Left (negative x) and up (positive y).

Answer: Quadrant II

⚙️ Functions

A function is a relation where every input has exactly one output. If an x-value is paired with two different y-values, it's not a function.

Vertical line test

If any vertical line touches a graph more than once, the graph is not a function.

Function notation

f(x) = 3x − 1 means “the output of f for input x.” So f(4) = 3(4) − 1 = 11.

Outputs may repeat: {(1, 5), (2, 5)} is still a function. Only repeated inputs with different outputs break the rule.

✏️ Worked examples

Example 1: Function?

{(1, 2), (2, 4), (1, 6)}

The input 1 has two outputs, 2 and 6.

Answer: not a function

Example 2: Evaluate

f(x) = x2 + 1. Find f(−3).

(−3)2 + 1 = 9 + 1.

Answer: 10

Example 3: Find the input

g(x) = 2x + 5. For what x does g(x) = 17?

2x + 5 = 17, so 2x = 12.

Answer: x = 6

⛰️ Slope

The slope of a line tells how steep it is. It's the change in y divided by the change in x, often called rise over run.

Slope formula

m = (y2 − y1) ÷ (x2 − x1)

Positive slope

Line goes up from left to right.

Negative slope

Line goes down from left to right.

Zero slope

Horizontal line (y = a number).

Undefined slope

Vertical line (x = a number).

✏️ Worked examples

Example 1: Two points

Slope through (1, 2) and (4, 11)

(11 − 2) ÷ (4 − 1) = 9 ÷ 3.

Answer: 3

Example 2: Negative slope

Slope through (−2, 5) and (2, −1)

(−1 − 5) ÷ (2 − (−2)) = −6 ÷ 4.

Answer: −3/2

Example 3: Horizontal line

Slope through (3, 7) and (8, 7)

(7 − 7) ÷ (8 − 3) = 0 ÷ 5.

Answer: 0

📉 Graphing Linear Equations

An equation whose graph is a straight line is a linear equation. The most useful form is slope-intercept form:

y = mx + b

m is the slope and b is the y-intercept (where the line crosses the y-axis).

To graph y = 2x − 3: plot the y-intercept (0, −3), then use the slope 2 = 2/1 to go up 2 and right 1 to the next point. Draw the line through them.

The x-intercept is where the line crosses the x-axis. Find it by setting y = 0.

✏️ Worked examples

Example 1: Read slope and intercept

y = −4x + 7

m is the number with x, and b is the constant.

Answer: slope −4, y-intercept 7

Example 2: Is the point on the line?

Is (2, 1) on y = 3x − 5?

3(2) − 5 = 1. It matches.

Answer: yes

Example 3: x-intercept

Find the x-intercept of y = 2x − 8.

0 = 2x − 8, so 2x = 8.

Answer: x = 4, the point (4, 0)

✍️ Writing Linear Equations

To write the equation of a line, you need its slope (m) and y-intercept (b).

  1. If you're given two points, find the slope first.
  2. Put the slope and one point into y = mx + b and solve for b.
  3. Write the final equation with your m and b.

Example

Slope 3 through (2, 5): 5 = 3(2) + b → b = −1 → y = 3x − 1

✏️ Worked examples

Example 1: Slope and intercept

Slope −2, y-intercept 5

Just fill in y = mx + b.

Answer: y = −2x + 5

Example 2: Slope and a point

Slope 4 through (1, 3)

3 = 4(1) + b, so b = −1.

Answer: y = 4x − 1

Example 3: Two points

Through (0, 2) and (3, 8)

Slope: 6 ÷ 3 = 2. The point (0, 2) gives b = 2.

Answer: y = 2x + 2

🔁 Proportional Relationships

Two quantities are in a proportional relationship if their ratio y/x is always the same. That constant ratio is called the constant of proportionality, k.

y = kx

The graph is a straight line through the origin (0, 0). The slope of the line is k, which is also the unit rate.

A line like y = 2x + 3 is linear but not proportional, because it doesn't pass through the origin.

✏️ Worked examples

Example 1: Find k

x: 2, 4, 6   y: 7, 14, 21

7/2 = 14/4 = 21/6 = 3.5. The ratio is always the same.

Answer: k = 3.5, so y = 3.5x

Example 2: Proportional?

x: 1, 2, 3   y: 4, 6, 8

4/1 = 4 but 6/2 = 3. The ratios differ.

Answer: not proportional

Example 3: Use it

Apples cost $1.25 per pound. How much do 8 pounds cost?

y = 1.25x, so y = 1.25(8).

Answer: $10

🟦 Graphing Linear Inequalities

The graph of an inequality like y > 2x + 1 is a whole region of the plane, not just a line.

  1. Graph the boundary line y = 2x + 1. Use a dashed line for < or > (points on the line don't count) and a solid line for ≤ or ≥.
  2. Shade the side that makes the inequality true. For y > or y ≥, shade above. For y < or y ≤, shade below.
  3. Check with a test point, like (0, 0), if it isn't on the line.

✏️ Worked examples

Example 1: Line and shading

y ≤ −x + 3

≤ means solid, and “less than” means below.

Answer: solid line, shade below

Example 2: Test a point

Is (1, 5) a solution of y > 3x?

3(1) = 3. Is 5 > 3? Yes.

Answer: yes

Example 3: Test (0, 0)

Is (0, 0) a solution of y < 2x − 4?

0 < 2(0) − 4 means 0 < −4, which is false.

Answer: no
