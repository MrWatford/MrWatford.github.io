🗺️ What this page covers

A system of linear equations is two (or more) equations with the same variables. The solution is the ordered pair that makes every equation true, which is where the lines cross on a graph. Here we solve systems by graphing, substitution, and elimination, learn the special cases with no solution or infinitely many, and use systems to solve real problems.

  • 📈 Solving Systems by Graphing
    The solution is where the two lines cross.
  • 🔄 Solving Systems by Substitution
    Solve one equation for a variable and plug it into the other.
  • ➖ Solving Systems by Elimination
    Add or subtract the equations to cancel a variable.
  • 🔀 Special Cases of Linear Systems
    Parallel lines have no solution; the same line has infinitely many.
  • 📝 Using Systems to Solve Problems
    Two unknowns, two facts: write a system and solve.

📈 Solving Systems by Graphing

Graph both lines on the same coordinate plane. The point where they intersect is the solution, because it's on both lines.

  1. Write each equation in y = mx + b form.
  2. Graph both lines carefully.
  3. Find the intersection point and check it in both equations.

Checking a point

Is (2, 5) a solution of y = 2x + 1 and y = −x + 7? 2(2) + 1 = 5 ✔ and −2 + 7 = 5 ✔. Yes!

✏️ Worked examples

Example 1: Check a point

Is (1, 3) a solution of y = x + 2 and y = 3x?

1 + 2 = 3 ✔ and 3(1) = 3 ✔.

Answer: yes

Example 2: Check a point

Is (4, 0) a solution of x + y = 4 and x − y = 2?

4 + 0 = 4 ✔ but 4 − 0 = 4, not 2.

Answer: no

Example 3: Same y-intercept

y = 2x + 3 and y = −x + 3

Both lines cross the y-axis at 3, so they meet there.

Answer: (0, 3)

🔄 Solving Systems by Substitution

Substitution works best when one equation is already solved for a variable (like y = 2x − 1).

  1. Solve one equation for x or y, if it isn't already.
  2. Substitute that expression into the other equation.
  3. Solve for the one variable left.
  4. Plug that value back in to find the other variable.

Example

y = 2x and x + y = 9 → x + 2x = 9 → 3x = 9 → x = 3 → y = 6. Solution: (3, 6)

✏️ Worked examples

Example 1: Already solved

y = x + 3 and 2x + y = 12

2x + (x + 3) = 12, so 3x = 9 and x = 3. Then y = 6.

Answer: (3, 6)

Example 2: Solve for a variable first

x − y = 1 and 3x + 2y = 18

x = y + 1. 3(y + 1) + 2y = 18, so 5y = 15, y = 3, x = 4.

Answer: (4, 3)

Example 3: Negative values

y = −2x and x + y = 4

x − 2x = 4, so −x = 4 and x = −4. y = 8.

Answer: (−4, 8)

➖ Solving Systems by Elimination

Elimination works well when both equations are in the form Ax + By = C.

  1. Line up the equations so like terms are in columns.
  2. If one variable has opposite coefficients (like 3y and −3y), add the equations to cancel it. If the coefficients are the same, subtract.
  3. If neither works yet, multiply one equation by a number to make opposites.
  4. Solve, then substitute back to find the other variable.

Example

x + y = 10 and x − y = 4. Add: 2x = 14, so x = 7. Then 7 + y = 10, so y = 3.

✏️ Worked examples

Example 1: Add to eliminate

2x + y = 11 and 3x − y = 9

Add: 5x = 20, so x = 4. Then 8 + y = 11.

Answer: (4, 3)

Example 2: Subtract to eliminate

3x + 2y = 16 and x + 2y = 8

Subtract: 2x = 8, so x = 4. Then 4 + 2y = 8, so y = 2.

Answer: (4, 2)

Example 3: Multiply first

x + 3y = 7 and 2x − y = 0

Multiply the second by 3: 6x − 3y = 0. Add: 7x = 7, x = 1. Then y = 2.

Answer: (1, 2)

🔀 Special Cases of Linear Systems

Two lines in a plane can meet in three ways:

One solution

Different slopes. The lines cross once.

No solution

Same slope, different y-intercepts. The lines are parallel and never meet.

Infinitely many

Same slope and same y-intercept. It's really the same line.

When solving algebraically, if the variables cancel and you get something false (like 0 = 5), there's no solution. If you get something true (like 0 = 0), there are infinitely many.

✏️ Worked examples

Example 1: Parallel

y = 2x + 1 and y = 2x − 3

Same slope, different intercepts.

Answer: no solution

Example 2: Same line

y = 3x − 2 and 6x − 2y = 4

Solve the second for y: y = 3x − 2. It's the same line.

Answer: infinitely many solutions

Example 3: Algebra shows it

x + y = 5 and 2x + 2y = 7

Double the first: 2x + 2y = 10. Subtract: 0 = 3, which is false.

Answer: no solution

📝 Using Systems to Solve Problems

When a problem has two unknowns and gives you two facts, write one equation for each fact.

  1. Choose two variables, like a = adult tickets and s = student tickets.
  2. Write an equation for each fact (often one counts items and one counts money).
  3. Solve by substitution or elimination.
  4. Answer the question and check that it makes sense.

✏️ Worked examples

Example 1: Tickets

A show sold 50 tickets. Adults paid $10 and kids paid $6. They collected $380. How many adult tickets?

a + k = 50 and 10a + 6k = 380. 10a + 6(50 − a) = 380, so 4a = 80.

Answer: 20 adult tickets

Example 2: Coins

You have 15 coins, all dimes and quarters, worth $2.70. How many quarters?

d + q = 15 and 0.10d + 0.25q = 2.70. 0.10(15 − q) + 0.25q = 2.70, so 0.15q = 1.20.

Answer: 8 quarters

Example 3: Sum and difference

Two numbers have a sum of 40 and a difference of 12. Find them.

x + y = 40 and x − y = 12. Add: 2x = 52.

Answer: 26 and 14
