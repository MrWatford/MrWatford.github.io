Adding Integers

Integers are whole numbers and their opposites: …, −3, −2, −1, 0, 1, 2, 3, … Here's how to add them, even when some are negative.

💡 The big idea

Picture a number line. Adding a positive number means moving right. Adding a negative number means moving left. Start at the first number, then move by the second.

You can also use two short rules. Both depend on absolute value, which is a number's distance from zero (so |−6| = 6 and |6| = 6).

Rule 1: Same signs

Add the absolute values. Keep the sign they share.

Rule 2: Different signs

Subtract the smaller absolute value from the larger. Use the sign of the number farther from zero.

Mr. WatfordQuick check: a number plus its opposite always equals zero, like −9 + 9 = 0. These are called additive inverses.

✏️ Worked examples

Example 1: Two negatives

−6 + (−9)

Same signs, so add the absolute values: 6 + 9 = 15. Both numbers are negative, so the answer is negative.

Answer: −15

Example 2: Negative plus positive

−11 + 4

Different signs, so subtract: 11 − 4 = 7. The −11 is farther from zero than the 4, so the answer is negative.

Answer: −7

Example 3: Positive plus negative

14 + (−5)

Different signs, so subtract: 14 − 5 = 9. The 14 is farther from zero, so the answer is positive.

Answer: 9

Example 4: A real-life problem

Early one winter morning it was −4°F. By noon the temperature had gone up 13 degrees. What was the noon temperature?

Going up means adding a positive: −4 + 13. Different signs, so subtract: 13 − 4 = 9. The 13 is farther from zero, so the answer is positive.

Answer: 9°F
