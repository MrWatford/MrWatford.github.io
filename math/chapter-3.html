🗺️ What this chapter covers

An equation says two expressions are equal, like x + 5 = 12. Solving means finding the value of the variable that makes it true. We use inverse operations to get the variable alone, step by step, and then use equations to solve real problems. Last, we work with inequalities, which have many solutions.

⚖️ Solving Equations by Adding or Subtracting

Think of an equation like a balance scale. To keep it balanced, whatever you do to one side, you must do to the other.

To get the variable alone, use the inverse operation. If a number is added to the variable, subtract it from both sides. If a number is subtracted, add it to both sides.

Always check

Put your answer back into the original equation. If both sides match, you're right.

✏️ Worked examples

Example 1: Subtract to undo adding

x + 9 = 4

Subtract 9 from both sides: x = 4 − 9. Check: −5 + 9 = 4 ✔

Answer: x = −5

Example 2: Add to undo subtracting

y − 13 = −2

Add 13 to both sides: y = −2 + 13. Check: 11 − 13 = −2 ✔

Answer: y = 11

Example 3: Variable on the right

20 = n + 26

Subtract 26 from both sides: 20 − 26 = n.

Answer: n = −6

🔁 Solving Equations by Multiplying or Dividing

If the variable is multiplied by a number, divide both sides by that number. If the variable is divided by a number, multiply both sides by that number.

Divide to undo multiplying

6x = 42
6x ÷ 6 = 42 ÷ 6
x = 7

Multiply to undo dividing

n ÷ 4 = −3
n = −3 · 4
n = −12

Remember the integer sign rules: −5x = 35 means x = 35 ÷ (−5) = −7.

✏️ Worked examples

Example 1: Divide

−8y = 64

Divide both sides by −8.

Answer: y = −8

Example 2: Multiply

x/5 = 9

Multiply both sides by 5.

Answer: x = 45

Example 3: Negative divisor

a/(−3) = −7

Multiply both sides by −3: (−7)(−3).

Answer: a = 21

👣 Solving Two-Step Equations

A two-step equation needs two inverse operations, like 3x + 4 = 19. Work backwards from the order of operations:

  1. Undo the adding or subtracting first.
  2. Then undo the multiplying or dividing.

Example

3x + 4 = 19 → subtract 4 → 3x = 15 → divide by 3 → x = 5

✏️ Worked examples

Example 1: Subtract, then divide

5x + 6 = 41

5x = 35, then x = 7. Check: 5(7) + 6 = 41 ✔

Answer: x = 7

Example 2: Add, then divide

−4y − 3 = 17

Add 3: −4y = 20. Divide by −4.

Answer: y = −5

Example 3: Add, then multiply

n/3 − 2 = 6

Add 2: n/3 = 8. Multiply by 3.

Answer: n = 24

🧹 Simplifying Before Solving

Some equations need cleaning up before you can solve them.

  1. Distribute to remove parentheses.
  2. Combine like terms on each side.
  3. If the variable is on both sides, add or subtract to move all variable terms to one side.
  4. Solve the two-step equation that's left.

Tip

Move the smaller variable term so you don't end up with a negative coefficient: in 7x + 2 = 3x + 18, subtract 3x from both sides.

✏️ Worked examples

Example 1: Combine like terms

4x + 3 + 2x = 27

6x + 3 = 27. Subtract 3: 6x = 24.

Answer: x = 4

Example 2: Distribute

3(y − 2) = 21

3y − 6 = 21. Add 6: 3y = 27.

Answer: y = 9

Example 3: Variables on both sides

7n + 2 = 3n + 18

Subtract 3n: 4n + 2 = 18. Subtract 2: 4n = 16.

Answer: n = 4

📝 Using Equations to Solve Problems

Use these steps for word problems:

  1. Read carefully. What are you trying to find?
  2. Choose a variable for the unknown.
  3. Write an equation using the key words and facts.
  4. Solve it.
  5. Check that your answer makes sense in the story.

Mr. WatfordIf you're stuck, try guessing an answer and checking it. Your guesses can show you how the equation should look.

✏️ Worked examples

Example 1: Consecutive numbers

The sum of two consecutive integers is 53. Find the smaller one.

Let n be the smaller and n + 1 the larger. n + n + 1 = 53, so 2n = 52.

Answer: 26

Example 2: Rate problem

A plumber charges $40 to come out plus $55 per hour. A job cost $205. How many hours?

40 + 55h = 205, so 55h = 165.

Answer: 3 hours

Example 3: Comparing

Ana has 4 times as many stickers as Ben. Together they have 85. How many does Ben have?

Let b = Ben's stickers. b + 4b = 85, so 5b = 85.

Answer: 17

🎯 Practice

↕️ Solving Inequalities

An inequality uses <, >, ≤ (less than or equal to), or ≥ (greater than or equal to). It usually has many solutions. x > 3 means every number bigger than 3 works.

Solve inequalities just like equations, with one important rule:

The flip rule

When you multiply or divide both sides by a negative number, flip the inequality sign.
−2x < 10 → x > −5

On a number line, use an open circle for < or > (the number is not included) and a closed circle for ≤ or ≥ (the number is included).

✏️ Worked examples

Example 1: One step

x + 6 > 2

Subtract 6 from both sides. No flip needed.

Answer: x > −4

Example 2: Dividing by a negative

−3y ≥ 12

Divide by −3 and flip ≥ to ≤.

Answer: y ≤ −4

Example 3: Two steps

4n − 5 < 11

Add 5: 4n < 16. Divide by 4 (positive, no flip).

Answer: n < 4

🛒 Using Inequalities

Words like these tell you to use an inequality:

≤

at most, no more than, maximum

≥

at least, no less than, minimum

<

less than, fewer than, under

>

more than, greater than, over

After solving, think about the story. You can't buy 4.6 tickets, so you might need to round to a whole number that still fits.

✏️ Worked examples

Example 1: At most

You have $40. Shirts cost $12. What is the most shirts you can buy?

12s ≤ 40, so s ≤ 3.33… You can only buy whole shirts.

Answer: 3 shirts

Example 2: At least

You need at least 80 points. You have 52. Each quiz is worth 7 points. How many quizzes do you need?

52 + 7q ≥ 80, so 7q ≥ 28 and q ≥ 4.

Answer: at least 4 quizzes

Example 3: Writing one

A ride requires riders to be at least 48 inches tall. Write an inequality for height h.

“At least” means greater than or equal to.

Answer: h ≥ 48
