⚖️ Variables on Both Sides

When a variable appears on both sides, use addition or subtraction to move all the variable terms to one side and all the plain numbers to the other side.

  1. Distribute and combine like terms on each side, if needed.
  2. Add or subtract to get the variable terms together. Moving the smaller one keeps the coefficient positive.
  3. Solve the two-step equation that's left, then check.

Example

5x − 3 = 2x + 9 → subtract 2x → 3x − 3 = 9 → add 3 → 3x = 12 → x = 4

✏️ Worked examples

Example 1: Basic

7n + 4 = 3n + 20

Subtract 3n: 4n + 4 = 20. Subtract 4: 4n = 16.

Answer: n = 4

Example 2: Negative answer

2y − 5 = 6y + 11

Subtract 2y: −5 = 4y + 11. Subtract 11: −16 = 4y.

Answer: y = −4

Example 3: Distribute first

3(k + 2) = 5k − 8

3k + 6 = 5k − 8. Subtract 3k: 6 = 2k − 8. Add 8: 14 = 2k.

Answer: k = 7

♾️ Identities and Contradictions

Sometimes the variable terms cancel out completely. Then look at what's left:

Identity: always true

2(x + 3) = 2x + 6 → 6 = 6
Every number works. The solution is all real numbers.

Contradiction: never true

3x + 1 = 3x + 5 → 1 = 5
No number works. There is no solution.

Most equations are neither: they have exactly one solution.

✏️ Worked examples

Example 1: Identity

4(x − 2) = 4x − 8

4x − 8 = 4x − 8. Subtract 4x: −8 = −8, which is always true.

Answer: all real numbers

Example 2: Contradiction

5y + 3 = 5y − 1

Subtract 5y: 3 = −1, which is never true.

Answer: no solution

Example 3: One solution

2n + 7 = 5n + 7

Subtract 2n: 7 = 3n + 7. Subtract 7: 0 = 3n.

Answer: n = 0

📝 Applying Equations

Many real problems compare two options or two quantities that end up equal. Write an expression for each one, set them equal, and solve.

  1. Choose a variable for the unknown.
  2. Write an expression for each side of the comparison.
  3. Set them equal and solve.
  4. Answer the question in a sentence and check that it makes sense.

Mr. WatfordA quick sketch or table can help you see how the two sides change.

✏️ Worked examples

Example 1: Comparing plans

Plan A: $20 plus $4 per hour. Plan B: $9 per hour. When do they cost the same?

20 + 4h = 9h. Subtract 4h: 20 = 5h.

Answer: 4 hours

Example 2: Perimeter

A rectangle's length is 3 more than twice its width. The perimeter is 42 cm. Find the width.

2w + 2(2w + 3) = 42, so 6w + 6 = 42 and 6w = 36.

Answer: 6 cm

Example 3: Ages

Dad is 3 times as old as Sam. In 12 years, Dad will be twice as old as Sam. How old is Sam now?

3s + 12 = 2(s + 12), so 3s + 12 = 2s + 24.

Answer: 12 years old

↕️ Solving Multi-Step Inequalities

Solve inequalities with the same steps as equations: distribute, combine like terms, gather variables on one side, then isolate the variable.

Don't forget the flip rule

If you multiply or divide both sides by a negative number, reverse the inequality sign.

To avoid dividing by a negative, move the variable terms to the side where the coefficient stays positive.

✏️ Worked examples

Example 1: Both sides

6x − 5 > 2x + 7

Subtract 2x: 4x − 5 > 7. Add 5: 4x > 12.

Answer: x > 3

Example 2: Flip the sign

3 − 4y ≤ 15

Subtract 3: −4y ≤ 12. Divide by −4 and flip.

Answer: y ≥ −3

Example 3: Distribute

2(n + 6) < 5n

2n + 12 < 5n. Subtract 2n: 12 < 3n.

Answer: n > 4 (same as 4 < n)

🎯 Practice

🛒 Applying Inequalities

Inequalities describe limits: a budget, a minimum score, a weight limit. Key phrases:

≤

at most, no more than, maximum

≥

at least, no less than, minimum

When comparing two options, an inequality tells you when one is the better deal. Always check whether the answer must be a whole number, and round in the direction that still fits the limit.

✏️ Worked examples

Example 1: Better deal

Pass A: $40 plus $2 a ride. Pass B: $6 a ride. For how many rides is Pass A cheaper?

40 + 2r < 6r, so 40 < 4r and r > 10.

Answer: more than 10 rides

Example 2: Average score

Your test scores are 82 and 88. What must you score on the third test to average at least 85?

(82 + 88 + s) ÷ 3 ≥ 85, so 170 + s ≥ 255.

Answer: at least 85

Example 3: Budget

You have $60. You buy a $15 shirt. Socks cost $4 a pair. How many pairs can you buy at most?

15 + 4p ≤ 60, so 4p ≤ 45 and p ≤ 11.25.

Answer: 11 pairs

🎯 Practice

² Equations with Powers

To solve an equation like x2 = 49, take the square root of both sides. There are two answers because both 7 · 7 and (−7)(−7) equal 49. We write x = ±7 (“plus or minus 7”).

Get the square alone first

2x2 − 8 = 42 → 2x2 = 50 → x2 = 25 → x = ±5

Special cases

x2 = 0 has one solution: x = 0.
x2 = −4 has no real solution.

For cubes, there's only one real answer: x3 = −27 → x = −3.

✏️ Worked examples

Example 1: Two solutions

x2 = 81

9 · 9 = 81 and (−9)(−9) = 81.

Answer: x = ±9

Example 2: Isolate first

3n2 + 4 = 52

Subtract 4: 3n2 = 48. Divide by 3: n2 = 16.

Answer: n = ±4

Example 3: Real life

A square rug has an area of 64 square feet. How long is each side?

s2 = 64. A length can't be negative.

Answer: 8 feet

√ Radical Equations

A radical equation has the variable under a root sign, like √x = 6. To solve it:

  1. Get the square root alone on one side.
  2. Square both sides to undo the root.
  3. Solve, then check in the original equation.

Watch out

A square root (√) is never negative. So √x = −3 has no solution.

✏️ Worked examples

Example 1: Square both sides

√x = 9

(√x)2 = 92.

Answer: x = 81

Example 2: Isolate first

√n + 4 = 11

Subtract 4: √n = 7. Square: n = 49. Check: 7 + 4 = 11 ✔

Answer: n = 49

Example 3: Expression inside

√(2x + 1) = 5

Square: 2x + 1 = 25. Then 2x = 24.

Answer: x = 12

🎯 Practice

Solve: √y = 10
Solve: √m − 3 = 5
