⭐ The four you should NEVER forget

Ctrl + C CopyCtrl + V PasteCtrl + Z UndoCtrl + A Select all

Editing

ShortcutWhat it does
Ctrl + CCopy. Highlight a word and copy it.
Ctrl + VPaste the copied word somewhere else.
Ctrl + XCut. Remove text so you can move it somewhere else.
Ctrl + ZUndo. Deleted a paragraph by accident? Bring it back.
Ctrl + YRedo. Undid something by mistake? Do it again.
Ctrl + ASelect all. Highlight everything on the page.

Formatting

ShortcutWhat it does
Ctrl + BBold
Ctrl + IItalicize
Ctrl + UUnderline

Files, finding, and links

ShortcutWhat it does
Ctrl + SSave. Google Docs saves automatically, but many programs don't.
Ctrl + PPrint
Ctrl + FFind. Type a word to find every place it appears.
Ctrl + KInsert a link on highlighted words.
Ctrl + Shift + VPaste without formatting (no strange fonts or colors).
Ctrl + EnterPage break. Start typing on a new page.

Text alignment

ShortcutWhat it does
Ctrl + Shift + LAlign left
Ctrl + Shift + ECenter (great for titles)
Ctrl + Shift + RAlign right
Ctrl + Shift + JJustify (both sides line up evenly)

Google Docs

ShortcutWhat it does
Ctrl + Alt + MAdd a comment
Ctrl + Shift + 7Numbered list (1, 2, 3)
Ctrl + Shift + 8Bulleted list (•)
Ctrl + Shift + CWord count
